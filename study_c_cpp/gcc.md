GCC 编译的通用命令格式如下：
bash
gcc [编译选项] <源文件> [-o 输出文件]
请谨慎使用此类代码。

1. 最核心的完整格式

通常我们写成这样：
bash
gcc -Wall -g -O2 src1.c src2.c -o my_program
请谨慎使用此类代码。

2. 各部分参数拆解

• [编译选项]（可选，但常用）：用来控制编译行为。
	• -Wall：开启所有常用警告（强烈建议加上，能帮你发现潜在的 Bug）。
	• -g：生成调试信息（如果需要用 gdb 调试，必须加这个）。
	• -O0 / -O1 / -O2 / -O3：优化级别（-O0 不优化，用于调试；-O2 常用作发布版本）。
	• -c：只编译成目标文件（.o），不进行链接。
	• -std=c11：指定 C 语言标准（例如使用 C11 或 C99 标准）。
• <源文件>（必填）：你的 C 语言源代码文件，可以是一个或多个。
	• 例如：main.c 或 main.c tools.c。
• -o <输出文件>（可选）：指定生成的可执行文件名。
	• 注意：-o 后面必须紧跟你想生成的程序名字（如 -o app）。
	• 如果不写 -o app，GCC 会默认生成一个名为 a.out（Linux/Mac）或 a.exe（Windows）的文件。

3. 高级编译格式（涉及头文件和库）

如果你的项目结构比较复杂，需要引入其他目录的头文件或第三方库，格式会扩展为：
bash
gcc 源文件.c -I <头文件目录> -L <库目录> -l<库名> -o 可执行文件
请谨慎使用此类代码。
• -I（大写 i）：指定第三方头文件（.h）的搜索路径。
• -L（大写 l）：指定第三方库文件（.a 或 .so）的存放路径。
• -l（小写 l）：指定要链接的具体库名（例如链接数学库写 -lm，链接多线程库写 -lpthread）。
