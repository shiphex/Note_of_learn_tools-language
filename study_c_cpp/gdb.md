### 1. 启动与退出

| 命令 | 完整写法 | 说明 |
| --- | --- | --- |
| `gdb ./app` | - | 加载并调试可执行程序 `app` |
| `gdb ./app core` | - | 结合 Core 崩溃转储文件加载调试 |
| `r` | `run` | 开始运行被调试的程序 |
| `q` | `quit` | 退出 GDB 调试器 |

---

### 2. 断点管理 (Breakpoints)

| 命令 | 示例 | 说明 |
| --- | --- | --- |
| `b` | `b main` / `b 22` | 在函数 `main` 或第 22 行设置断点 |
| `info b` | `info breakpoints` | 查看当前设置的所有断点列表及编号 |
| `d <编号>` | `delete 1` | 删除编号为 1 的断点 |
| `d` `delete` |  | 删除全部断点 |
| `disable <编号>` | `disable 1` | 禁用指定断点（不删除） |
| `enable <编号>` | `enable 1` | 启用指定断点 |
| `wa <变量>` | `watch g_Boxes` | 设置数据观察点，当变量值发生改变时自动暂停 |

---

### 3. 执行控制与单步调试

| 命令 | 级别 | 类型 | 说明 |
| --- | --- | --- | --- |
| `c` | - | 全速 | `continue`，继续运行直到遇到下一个断点或崩溃 |
| `n` | 源码级 | 步过 | `next`，执行下一行 C 代码；不进入子函数内部 |
| `s` | 源码级 | 步入 | `step`，执行下一行 C 代码；若有子函数则进入内部 |
| `ni` | 汇编级 | 步过 | `nexti`，执行下一个机器指令；不进入 `call` 函数内部 |
| `si` | 汇编级 | 步入 | `stepi`，执行下一个机器指令；若为 `call` 则进入子函数 |
| `finish` | - | 跳出 | 运行完当前函数剩余代码，返回上一层并打印返回值 |
| `until <行号>` | - | 跳出 | 运行直到到达指定行号（常用于跳出循环） |

---

### 4. 栈帧与崩溃定位 (Stack Trace)

| 命令 | 缩写/示例 | 说明 |
| --- | --- | --- |
| `bt` | `backtrace` | 打印函数调用栈，直接定位程序崩溃点和调用链路 |
| `f <编号>` | `frame 0` | 切换到指定编号的函数调用栈帧 |
| `info f` | `info frame` | 查看当前栈帧的详细参数、局部变量和指令指针地址 |
| `up` / `down` | - | 在调用栈的上一层（调用者）与下一层（被调用者）之间移动 |

---

### 5. 变量打印与内存检查

| 命令 | 示例 | 说明 |
| --- | --- | --- |
| `p` | `p g_Boxes[0]` | `print`，打印变量、结构体或数组的具体数值 |
| `p` | `p i + j` | 打印多个变量的计算式 |
| `p <指针>`| `p *a` | 打印地址处的值 |
| `p &a`|`p &a` | 打印变量的地址 |
| `p/x <变量>` | `p/x val` | 以 16 进制格式打印变量值（`/d` 十进制，`/t` 二进制） |
| `ptype` | `ptype g_Boxes` | 查看变量、结构体或类的数据类型定义 |
| `whatis` `what` | `whatis a` `whatis` | 检查变量类型 |
| `info registers` | `i r` | 查看所有 CPU 寄存器当前的具体数值 |
| `x/i $pc` | - | 检查（`examine`）`$pc` 寄存器指向的当前机器指令反汇编 |
| `x/<n><f> <地址>` | `x/10xw 0x7ffffff` | 以指定格式检查内存数据（`n`数量，`f`格式：`x`十六进制/`i`指令，`w`字长） |

---

### 6. 源码查看与 TUI 模式

| 命令 | 快捷键 | 说明 |
| --- | --- | --- |
| `l` | `list` | 列出当前暂停位置附近的源代码 |
| `l <函数名>` | `list editBox` | 显示指定函数的源代码 |
| TUI 模式开关 | `Ctrl + X` 接着按 `A` | 进入或退出 TUI（源码与命令分屏）可视化模式 |
| 切换视图 | `Ctrl + X` 接着按 `2` | 在 TUI 中循环切换“源码”、“汇编”、“寄存器”组合窗口 |
| `ref` | `refresh` | 重绘并刷新被程序标准输出打乱的 TUI 界面 |

---

### 7. 显示

| 命令 | 快捷键 | 说明 |
| --- | --- | --- |
| `display` | `display a` | 每次程序暂停（如单步执行、触发断点或信号）时，自动打印变量或表达式 a 的当前值 |
| `undisplay` | `undisplay a` | 按编号取消自动显示 |
| `disable display` `enable display` | `disable display a` `enable display a` | 临时禁用/启用自动显示 |

---

### 8. 其他功能

| 命令 | 快捷键 | 说明 |
| --- | --- | --- |
| target record-full | 无（可简写为 target record） | 开启进程状态全记录，为后续的反向调试提供状态支持（需在程序停在断点后执行）。 |
reverse-next | rn | 反向单步跳过，回退到上一行源码（若包含函数调用，会直接撤销整个函数而不进入）。 |
set var x=15 | 无（var 为 variable 简写） | 调试时强行将变量 x 的值修改为 15（原问题中的 ver 为拼写误差）。 |
record stop | 无 | 停止记录并丢弃当前时间点之后的历史状态（用于回退后需要修改变量并重新运行的场景）。 |
