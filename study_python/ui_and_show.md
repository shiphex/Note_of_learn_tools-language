
## 控制终端颜色的 ANSI Escape Code

例如：
``` shell
\033[36m    # 输出青色
```
语法解析：
- `\033` 表示八进制值 033，即 ASCII 控制字符 `ESC`。
- 组合为 `ESC[36m` 表示输出青色。
- `\033[0m` 表示重置颜色，恢复默认颜色。

颜色列表：

| ANSI 代码 | 颜色       |
| ------- | -------- |
| `30`    | 黑色       |
| `31`    | 红色       |
| `32`    | 绿色       |
| `33`    | 黄色       |
| `34`    | 蓝色       |
| `35`    | 洋红       |
| `36`    | 青色（Cyan） |
| `37`    | 白色       |
| `90~97` | 高亮颜色     |
| `0`     | 恢复默认     |
